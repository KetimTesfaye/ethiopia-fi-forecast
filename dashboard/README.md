Financial Inclusion Dashboard (Ethiopia)

This dashboard provides interactive visualization and forecasting of financial inclusion metrics, including account ownership and digital payment adoption.

 Prerequisites
- Python 3.9+
- Pip
 Installation
1. Clone the repository and navigate to the project root.
2. Create a virtual environment:
   
```bash
   python -m venv venv
   source venv/bin/activate  

How to Run:
1. Ensure you are in the `ethiopia-fi-forecast` root directory.
2. Run: `streamlit run dashboard/app.py'
